Instalar el Gestor de Cartera

Complemento para Excel en la web que trabaja sobre el archivo de la cartera en OneDrive. No requiere TI ni instalar programas: cada persona lo carga una vez desde Excel.

1Descarga el manifiesto

Se detecta sola. Solo cámbiala si el complemento se mueve a otra dirección (debe empezar con https://).


  


  

    
2Cárgalo en Excel para la web

    
    
      
  1. Abre el archivo de la cartera desde OneDrive en Excel para la web.
    2. 
      
  2. Ve a Inicio → Complementos (en algunas versiones: Insertar → Complementos → Obtener complementos).
    3. 
      
  3. Elige Mis complementos y luego Cargar mi complemento.
    4. 
      
  4. Selecciona el manifest.xml que descargaste y pulsa Cargar.
    5. 
      
  5. Aparece el botón Gestor de Cartera en la pestaña Inicio. Púlsalo para abrir el panel.
    6. 
    

    
Si no ves «Cargar mi complemento», tu organización lo tiene bloqueado y solo un administrador de Microsoft 365 puede habilitarlo.

  


  

    
3Primer uso

    
    
      
  1. La primera persona que abre el panel en el archivo lo configura y queda como administrador.
    2. 
      
  2. El administrador crea a cada ejecutivo con un PIN temporal; al entrar, cada uno crea el suyo.
    3. 
      
  3. La hoja de la cartera no se modifica: el sistema solo agrega comentarios en «Comentario Créditos» y guarda lo demás en pestañas internas muy ocultas.
    4.
